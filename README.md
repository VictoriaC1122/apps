# VictoriaC1122 Apps Site

Standalone bilingual app showcase site for Victoria Cheng.

## Files

- `index.html`: single-page app showcase
- `styles.css`: visual style and responsive layout
- `script.js`: bilingual content and card rendering
- `assets/icons/`: local app icons from Xcode asset catalogs and official App Store artwork

## Notes

- All twelve featured apps are published and have confirmed App Store links, with Taiwan links for Chinese and US links for English.
- Versions and store titles were checked on 2026-10-14 using Apple's Lookup API for developer `1851202446` (Yung Wen Cheng), in both Taiwan and the US.
- Both Lookup catalogs list the same twelve apps. Added `Coffee Chat Note` (6820863958), including its official icon and bilingual description. Updated `Stock Mastery: Paper Trading` to 2.4.0 and `Perfect Pig` to 1.1.1.
- Sources: [Taiwan catalog](https://itunes.apple.com/lookup?id=1851202446&entity=software&country=tw&limit=200), [US catalog](https://itunes.apple.com/lookup?id=1851202446&entity=software&country=us&limit=200), [developer page](https://apps.apple.com/tw/developer/yung-wen-cheng/id1851202446).
